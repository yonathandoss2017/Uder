### Instalación
<details><summary>Clic para ver</summary>

1. Clone el proyecto desde el repositorio:

```bash
https://git.utec.edu.uy/pft/proyecto-web.git
```

2. En su IDE, diríjase a:
   **Menu → New → Project from Version Control…**

![New Project](https://git.utec.edu.uy/pft/proyecto-web/-/raw/master/documentos/screenshots%20ReadMe/Version_Control.JPG?ref_type=heads)

3. Pegue el enlace en el campo **URL** y seleccione el directorio donde desea guardar el proyecto.

![URL Git](https://git.utec.edu.uy/pft/proyecto-web/-/raw/master/documentos/screenshots%20ReadMe/URL-GIT.JPG?ref_type=heads)

4. Haga clic en **Clone** para importar el proyecto.

![button Done](https://git.utec.edu.uy/pft/proyecto-web/-/raw/master/documentos/screenshots%20ReadMe/button-Done.JPG?ref_type=heads)

5. Seleccione la ubicación donde se guardará el proyecto.

### Ejecución del Proyecto

<details><summary>Clic para ver</summary>

#### Modo Desarrollo:

1. Ejecute el siguiente comando para iniciar el proyecto en modo desarrollo:

   ```bash
   npm run dev
   ```

2. Abra [http://localhost:3000](http://localhost:3000) en su navegador para ver el resultado.

#### Modo Producción:

1. Construya el proyecto ejecutando:

   ```bash
   npm run build
   ```

2. Inicie el proyecto con:
   ```bash
   npm run start
   ```
   

#### Modo Producción con https:

1. Construya el proyecto ejecutando:

   ```bash
   npm run build
   ```

2. Inicie el proyecto con:
   ```bash
   npm run start-https
   ```
</details>
